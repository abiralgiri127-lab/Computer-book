Unit 5: Programming Concepts and Logics


5.1 Programming Language Concepts

Definition: A programming language is a formal set of instructions, commands, and syntax used to create software programs and communicate instructions to a computer.


5.1.1 Levels of Programming Languages

Low-Level Languages:

Machine Language (1st Generation): Written purely in binary code (0s and 1s). Executed directly by the CPU without translation, but extremely difficult to write and hardware-dependent.

Assembly Language (2nd Generation): Uses symbolic codes called mnemonics (e.g., ADD, MOV, SUB). Requires an Assembler to translate into machine code.

High-Level Languages (3rd Generation & Beyond): Written using human-readable English-like statements and mathematical expressions (e.g., C, C++, Java, Python). Machine-independent and easy to debug.


5.1.2 Language Translators

Compiler: Translates the entire high-level source code into machine code (object code) all at once. Generates an executable file (.exe) and lists all errors after compilation (e.g., C, C++).

Interpreter: Translates and executes high-level source code line-by-line. Stops execution immediately when an error is encountered (e.g., Python, BASIC).

Assembler: Translates assembly language mnemonics into binary machine code.


5.2 Program Design Tools

Algorithm: A step-by-step, finite sequence of logical instructions written in plain natural language to solve a specific problem.

Flowchart: A pictorial or graphical representation of an algorithm using standard geometric symbols connected by flow lines.

Terminal (Oval): Start / Stop.

Input/Output (Parallelogram): Read data or display output.

Processing (Rectangle): Calculations and data assignments.

Decision (Diamond): Logical conditions (True/False branching).

Flow Lines (Arrows): Indicates the direction of program execution.

Connector (Circle): Connects different parts of a flowchart.

Pseudocode: An informal, high-level description of a computer program's logic written in structured plain text before actual coding.


5.3 Control Structures

Control structures dictate the flow of execution in a program:

Sequential Structure: Instructions are executed line-by-line in the exact order they are written.

Selection / Decision Structure: Executes specific code blocks based on whether a condition is True or False (e.g., if, if-else, switch/case).

Iteration / Looping Structure: Repeats a block of code multiple times as long as a specified condition remains True (e.g., for, while, do-while).


5.4 C Programming Fundamentals

Introduction to C: Developed by Dennis Ritchie at AT&T Bell Laboratories in 1972. It is a structured, procedural high-level language.


5.4.1 Structure of a C Program

C
#include  // Header File

int main() {       // Main Function
    // Statements / Code execution
    printf("Hello World!");
    return 0;      // Return Statement
}

5.4.2 Basic Elements of C

Character Set: Letters (A-Z, a-z), Digits (0-9), and Special Symbols (+, -, *, ;, etc.).

Keywords: Reserved words with predefined meanings in the compiler (32 standard keywords in C, e.g., int, float, if, else, while, return).

Identifiers: User-defined names given to variables, functions, and arrays.

Constants: Fixed values that do not change during program execution (e.g., 10, 3.14, 'A').

Variables: Named memory locations used to hold data that can change during program execution.


5.4.3 Data Types in C

Primitive Data Types:

int: Integer values (e.g., 10, -5).

float: Single-precision floating-point real numbers (e.g., 3.14).

double: Double-precision floating-point real numbers.

char: Single characters enclosed in single quotes (e.g., 'a', '%').


5.4.4 Operators in C

Arithmetic Operators: +, -, *, /, % (Modulus / Remainder operator).

Relational Operators: <, >, <=, >=, == (equal to), != (not equal to).

Logical Operators: && (AND), || (OR), ! (NOT).

Assignment Operators: =, +=, -=, *=, /=.

Increment / Decrement Operators: ++ (Increments value by 1), -- (Decrements value by 1).


5.4.5 Input/Output Functions

Formatted I/O: printf() (outputs text/data to screen using format specifiers like %d, %f, %c) and scanf() (reads user input using addresses &variable).

Unformatted I/O: getchar(), putchar(), gets(), puts().
