Unit 6: Web Technology I


6.1 Introduction to Web Technology

World Wide Web (WWW): A system of interlinked hypertext documents accessed via the Internet using web browsers.

Web Page: A digital document written in HTML accessible through the Internet.

Website: A collection of related, interlinked web pages hosted under a single domain name.

Static vs. Dynamic Web Pages:

Static Web Page: Displays fixed content that remains identical for every user; built primarily using HTML and CSS.

Dynamic Web Page: Displays real-time, interactive content that changes based on user input, time, or database records; uses client/server-side scripting (JavaScript, PHP, etc.).

Web Server: A specialized computer system running server software (e.g., Apache, Nginx) that hosts website files and serves them to client browsers via HTTP/HTTPS protocols.

Web Browser: A client software application used to retrieve, render, and display web pages (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge).

URL (Uniform Resource Locator): The complete web address used to locate a specific resource on the Internet (e.g., [https://www.example.com/index.html](https://www.example.com/index.html)).

      6.3.3 Hyperlinks and Images
      
Hyperlinks (      ): Connects to other web pages or external resources.

Attribute href: Specifies the target URL.

Attribute target="_blank": Opens the linked document in a new browser tab.

Images (): Embeds visual media into a page.

Attribute src: Path or URL of the image file.

Attribute alt: Alternative descriptive text displayed if the image fails to load.

Attributes width and height: Defines image display dimensions.
