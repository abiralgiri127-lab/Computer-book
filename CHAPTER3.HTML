Unit 3: Computer Software and Operating System


3.1 Computer Software

3.1.1 Definition and Concept
Definition: Computer software is a collection of programs, procedures, rules, and documentation that instructs computer hardware on how to perform specific tasks. Hardware represents the physical components, whereas software acts as the logical interface enabling hardware operation.

Software Classification:

System Software: Controls internal system hardware, manages system resources, and provides an environment for running user application software.

Application Software: Performs specific user-oriented tasks such as document editing, financial accounting, web browsing, and graphic design.


3.1.2 System Software

Operating System (OS): Main system program that acts as an intermediary between user application software and physical hardware.

Language Translators: Converts high-level or assembly language code into machine-executable code.

Assembler: Translates Assembly language programs into Machine code.

Compiler: Translates the entire high-level source code into machine code in a single execution run.

Interpreter: Translates high-level source code line-by-line into machine code, executing each line immediately.

Utility Software: Maintenance software designed to optimize system performance and security (e.g., Disk Defragmenter, Antivirus, Backup tools).

Device Drivers: Specialized programs enabling the operating system to communicate directly with specific hardware peripherals (e.g., printer drivers, display drivers).


3.1.3 Application Software

Packaged Software (General Purpose): Mass-produced software created for broad commercial use (e.g., Microsoft Word, Excel, Photoshop).

Tailored Software (Customized): Purpose-built software engineered to fulfill specific organizational requirements (e.g., Telecom billing system, school management systems).


3.2 Operating System (OS)


3.2.1 Definition, Objectives, and Functions

Definition: An Operating System is a master system software program that manages hardware resources, executes user software, and provides common services for computer programs.

Core Objectives: Convenience for the user, efficient system hardware resource utilization, and isolated task execution.

Key Functions:

Process Management: Schedules, allocates CPU processing time, and handles multi-tasking and process synchronization.

Memory Management: Allocates, tracks, and deallocates main RAM memory space for executing applications.

File Management: Manages file directories, storage access permissions, file creation, deletion, and file system organization.

Device Management: Manages hardware peripherals using input/output buffering, queuing, and dedicated device drivers.

Security and User Interface: Protects data via password user accounts, permissions, and provides interaction interfaces (GUI/CLI).


3.2.2 Types of Operating System

Based on User Interface:

CLI (Command Line Interface): Text-based interface where operations require typed command syntax (e.g., MS-DOS).

GUI (Graphical User Interface): Visual interface using Windows, Icons, Menus, and Pointer controls (e.g., Windows 11, macOS).

Based on User Capacity:

Single-User OS: Allows only one user to access system resources at a time (e.g., MS-DOS, Windows 95).

Multi-User OS: Allows multiple concurrent network users to access central system processing power and files simultaneously (e.g., Linux, Unix, Windows Server).

Based on Processing Mode:

Batch OS: Groups similar jobs into batches for sequential CPU processing without manual intervention.

Multi-Tasking / Time-Sharing OS: Shares CPU time slices across multiple active programs simultaneously.

Real-Time OS (RTOS): Guarantees instantaneous processing output within strict timing constraints (e.g., missile control, medical life support).


3.2.3 Open-Source and Proprietary Operating Systems

Open-Source OS: Operating systems whose underlying source code is freely available for modification, redistributions, and community audit (e.g., Linux distributions like Ubuntu, Debian, Fedora).

Proprietary OS: Closed-source software owned by a commercial entity, requiring a commercial user license for usage (e.g., Microsoft Windows, Apple macOS).


3.2.4 Mobile Operating System

Definition: Specialized operating systems designed explicitly for handheld mobile devices, smartphones, and tablets, optimized for low power usage, touch interfaces, cellular connectivity, and embedded sensors.

Popular Mobile OS Examples:

Android: Open-source mobile OS developed by Google based on the Linux kernel.

iOS: Proprietary mobile OS developed by Apple exclusively for iPhone hardware.
